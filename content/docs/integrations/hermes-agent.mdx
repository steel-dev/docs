:::callout
Steel is available as a [standalone browser-provider plugin](https://github.com/steel-dev/hermes-steel) for Hermes Agent 0.18.0 and newer. Install the plugin and explicitly select `steel` as the browser provider to route browser tasks through Steel.
:::

The plugin connects Hermes' browser tools to Steel cloud sessions and provides:

*   Steel-backed browser sessions for web navigation and interaction
*   A `steel_scrape` tool for server-side content extraction without a browser session
*   Optional residential proxies and CAPTCHA solving
*   A live viewer link so you can monitor browser sessions while the agent runs

### Requirements

*   **Hermes Agent**: Version 0.18.0 or newer
*   **Steel API key**: An active [Steel account](https://app.steel.dev) and [API key](https://app.steel.dev/settings/api-keys)

### Install and select the plugin

Install the plugin, enable it, and select Steel as the browser backend:

```bash Terminal
hermes plugins install steel-dev/hermes-steel --enable
hermes config set browser.cloud_provider steel
```

The installer prompts for your `STEEL_API_KEY` and saves it to `~/.hermes/.env`. Installing the plugin does not automatically change the browser backend: run the second command to route Hermes' browser tools through Steel.

### Browse with Hermes

Ask Hermes to perform a browser task:

```text
Find a hotel near Grand Central and show me the live browser session.
```

The plugin includes the Steel backend name and a live viewer link in the first browser result for each session. Open the viewer to inspect the browser while Hermes works.

### Optional proxy and CAPTCHA settings

Residential proxies and CAPTCHA solving are off by default. To enable them as persistent defaults:

```bash Terminal
hermes config set browser.steel.use_proxy true
hermes config set browser.steel.solve_captcha true
```

These features require a verified Steel account. If Steel declines an optional feature, the plugin can create the session without it and reports what was omitted. See [pricing and limits](/overview/pricinglimits) for account requirements.
