Hey everyone. This release improves billing visibility and performance, and fixes several reliability gaps in payments, session settings, and session recording.

### 🔧 Improvements

*   Billing usage pages now load daily breakdowns faster, open the Stripe billing portal only when requested, and show placeholders instead of provisional zero values.

### 🐛 Bug Fixes

*   Fixed Wallet purchases so declined or canceled payments show a terminal failure instead of remaining in a processing state.

*   Fixed auto top-up status when a recharge policy is disabled after a declined charge, including notifying the customer when this happens.

*   Fixed the Proxy & Network dashboard's Top domains query so it returns usage data instead of failing.

*   Fixed per-organization maximum session timeout overrides not applying to some sessions.

*   Fixed session replay recordings missing for some sessions.

*   Fixed tags on long-running sessions.
