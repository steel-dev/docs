Hey everyone. This release makes the billing pages faster and clearer, and fixes bugs in payments, session settings, and session recording.

### 🔧 Improvements

*   Billing usage pages load daily breakdowns faster and show placeholders while data loads instead of showing zero. The page also connects to the Stripe billing portal only when you open it.

### 🐛 Bug Fixes

*   Fixed Wallet purchases with a declined or canceled payment staying in processing. They now show as failed.

*   Fixed auto top-up status when a declined charge disables the recharge policy. The customer now gets a notification when this happens.

*   Fixed the Proxy & Network dashboard's Top domains query so it returns usage data again.

*   Fixed per-organization maximum session timeout overrides not applying to some sessions.

*   Fixed missing session replay recordings for some sessions.

*   Fixed tagging for long-running sessions.
