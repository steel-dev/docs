## Findings considered and rejected

- **Agent Skills CORS configuration:** no source change is planned. The live
  `index.json` already returns `Access-Control-Allow-Origin: *`. Plan 001 requires
  post-deploy verification for both the index and new archives; if that behavior
  changes, stop and scope a platform/header fix instead of assuming the current
  finding remains true.
- **A crawler denylist for the docs root:** originally rejected in favor of
  removing the absence-of-`Sec-Fetch-Dest` heuristic. PR #96 later resolved the
  broader representation policy by separating autonomous crawlers from
  user-directed clients.
- **`timeout: 120000` on `Bun.spawnSync`:** rejected. A direct probe on Bun 1.3.9
  confirmed that Bun's 120-second test timeout can interrupt the synchronous
  spawn and terminate its child. An identical inner timeout adds no earlier
  escape hatch; Plan 005 adds the missing workflow-level ceiling instead.
- **A blind fix for `result.stdout` being undefined:** rejected until the
  intermittent failure has a reproducer or diagnostic capture. Optional chaining,
  retries, or substituting an empty buffer would hide the spawn failure. Plan 005
  preserves an issue-ready investigation brief.
- **Changing Content Signals policy values:** rejected. The declarations are
  syntactically correct and do not block crawling. Plan 004 only repairs the test
  helper and removes the deprecated `Host` record.
- **Serving a second OpenAPI copy from the docs repo:** rejected. Plan 003 keeps
  the canonical API-owned URL and makes the catalog's media-type hint match the
  representation that URL actually serves.
- **Rebuilding schema from scratch:** rejected. `BreadcrumbList`, integration and recipe
  `TechArticle`, `FAQPage`, and author `ProfilePage` schema already exist. Plan 007 joins
  those nodes to one site and organization identity.
- **Homepage freshness schema:** rejected. There is no trustworthy homepage content date;
  build and filesystem times are not publication signals.
- **`SoftwareApplication` or `Product` schema in this task:** rejected. The docs homepage
  does not expose the complete product facts those schema types would claim.
